# APL121 · Бие даалт №1 — Code Quest

**Сэдэв №27 — Зогсоолын төлбөр**

Орсон ба гарсан цагаас зогссон минутыг тооцож, эхний 30 минут үнэгүй, дараа нь шатлалтай тарифаар төлбөр бодно. Өдрийн машинуудын хүснэгт хэвлэж, хамгийн удаан зогссон машиныг олно.

## Файлууд

| Файл | Агуулга |
|---|---|
| `quest.fprg` | Flowgorithm схем (Main + `CalcFee`, `PrintHeader`, `PrintRow`) |
| `flowchart.png` | Схемийн зураг (Flowgorithm-оос экспортолсон) |
| `pseudocode.md` | Схемтэй тохирох псевдокод |
| `main.c` | C хэл дээрх программ |
| `tests.md` | 5 тест (хилийн утга, буруу оролттой) |

## Ажиллуулах

```bash
gcc main.c -o main
./main          # Windows: main.exe
```

Windows-ийн консол дээр кирилл буруу харагдвал эхлээд `chcp 65001` гэж бичнэ. Flowgorithm: `quest.fprg`-г нээгээд **Run** (F5) дарна.

## Миний тогтоосон дүрмүүд

| Дүрэм | Утга |
|---|---|
| Үнэгүй хугацаа | эхний 30 минут |
| 31–60 минут | 1000 MNT |
| 61–180 минут | 2500 MNT |
| 181–480 минут | 5000 MNT |
| 481 минутаас дээш | 8000 MNT (өдрийн дээд) |
| Оршин суугчийн хөнгөлөлт | 20% (төлбөртэй үед) |
| Машины тоо | 5–10 |
| Хугацаа | зөвхөн нэг өдрийн дотор (00:00–23:59), гарсан цаг орсноос хойш |
| Дугаар | 0–9999 (тоон хэсэг) |

## Заавал байх 7 элемент

| № | Элемент | Хаана |
|---|---|---|
| 1 | Оролт/гаралт | `scanf` (дугаар, цаг, минут, оршин суугч), `printf` |
| 2 | Үйлдэл, илэрхийлэл | `inH * 60 + inM`, `fee * 20 / 100`; `&&`, `\|\|` |
| 3 | Нөхцөл | `if / else if / else` тарифын шат |
| 4 | Давталт ба хүснэгт | `for` — 5–10 мөр, `%-8d`, `%6d` тэгшлэлт |
| 5 | Дэд алгоритм | Flowgorithm: `CalcFee`, `PrintHeader`, `PrintRow` (`Call` блок). C: `main` дотор |
| 6 | Хайлт | `minutes > maxMinutes` — хамгийн удаан зогссон машин |
| 7 | Оролтын шалгалт | `do-while` — машины тоо, дугаар, цаг, оршин суугч |
